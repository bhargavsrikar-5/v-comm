# Firebase V1 source archive (reference only)

This folder preserves the older Flutter + Firebase Dart source, dependency manifest and Cloud Function for feature and design migration. It is not the active mobile application. Live Firebase configuration files, Android/iOS/macOS service files, and the separate Firebase admin HTML panel were intentionally omitted. The admin panel contained project-specific Firebase client configuration; it was reviewed but is not copied into this repository.

See [the legacy reference notes](../../docs/LEGACY_FIREBASE_REFERENCE.md).
