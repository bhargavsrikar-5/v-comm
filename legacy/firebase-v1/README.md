# Firebase V1 source archive (reference only)

This folder preserves the older Flutter + Firebase Dart source, dependency manifest, Cloud Function, and a sanitized Firebase admin-panel source copy for feature and design reference. It is not part of the active application. Live Firebase configuration files and Android/iOS/macOS service files are excluded. The admin-panel configuration contains placeholders only; do not deploy it or treat it as integrated with the Spring Boot API.

See [the legacy reference notes](../../docs/LEGACY_FIREBASE_REFERENCE.md).
