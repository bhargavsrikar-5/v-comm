# Historical Firebase admin panel (reference only)

This is a sanitized copy of the old Firebase admin-panel source, preserved for provenance. It is not part of the active Flutter or Spring Boot application and must not be deployed as-is.

The original embedded Firebase client configuration has been replaced with placeholders. This reference is intentionally not runnable until separately reviewed and configured. The panel calls Firebase Auth and Firestore directly; it has not been adapted to the active Spring Boot admin API or reviewed as a secure deployment. Password-bearing debug logging was removed.

See [the legacy Firebase source notes](../README.md).
